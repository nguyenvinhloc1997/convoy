# Convoy brand kit v1.0

Start with `Convoy-Brand-Guidelines.pdf`.

- `logo/svg`: the mark, horizontal lockup, stacked lockup and wordmark, each in four versions: `color-dark` (for dark backgrounds), `color-light` (for light backgrounds), `black` and `white`. All text is converted to outlines.
- `logo/png`: the same set as transparent PNGs at several widths.
- `icon`: square app icon (SVG, plus 1024/512/192 PNG) and `apple-touch-icon-180.png`.
- `favicon`: `favicon.ico` (16/32/48), `favicon.svg` (the micro chevron) and 16/32/48 PNGs.
- `social`: Open Graph card at 1200×630.
- `tokens`: `colors.css` and `tokens.json`.
- `fonts`: Barlow Condensed and JetBrains Mono (SIL OFL).

Colors: Ink #101214 · Graphite #15171A · Paper #ECE8DF · Amber #F2A23A · Amber Deep #C2680C · Mute #8A8F98
